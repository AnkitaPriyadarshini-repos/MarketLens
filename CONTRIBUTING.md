# Contributing to MarketLens

Thank you for your interest in contributing to MarketLens!

Please refer to the full [Documentation Contribution Guidelines](docs/CONTRIBUTING.md) for details on development setup, branch naming, commit standards, testing requirements, and PR expectations.

## Quick Summary

### Development Setup
```bash
git clone https://github.com/AnkitaPriyadarshini-repos/MarketLens.git
cd MarketLens
npm install
npm run dev
```

### Pre-Submission Verification
```bash
npm run typecheck
npm test
npm run benchmark
npm run build
```

### Branch Conventions
- `feature/<name>`
- `fix/<name>`
- `perf/<name>`
- `docs/<name>`
